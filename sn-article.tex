\section{Introduction}\label{sec1}

Spike-timing dependent plasticity (STDP) is a biologically plausible learning rule that has been widely used in spiking neural networks. When a pre-synaptic neuron fires shortly before a post-synaptic neuron, the synapse between them is strengthened. Conversely, if the pre-synaptic neuron fires shortly after the post-synaptic neuron, the synapse is weakened.

However, STDP is a fully local rule that cannot capture the global structure of the neural network. This issue is much more prominent when population vectors are used for inference via the population of neurons in different regions of the network. In order to ensure the expressivity of the population vectors, the neural network must have a modular structure, much like the cortical organization of the brain.

Moreover, the brain has been identified to perform both stochastic random walks and entropy maximization \cite{dayan2001information}, which are two major components of the map equation, an info-theoretic objective function for community detection in the Infomap algorithm. The map equation measures the modular structure of a network by quantifying the amount of information needed to describe the flow of activity through the network.

As such, a Map-STDP rule that incorporates the map equation is derived. The Map-STDP rule is a local learning rule that can capture the global modular structure of the neural network. Moreover, the Map-STDP rule preserves biorealism through the use of info-theoretic entropy maximization, stochastic neural dynamics, and local synaptic updates.
